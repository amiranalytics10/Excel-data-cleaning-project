# Excel-data-cleaning-project
A hands-on Excel project demonstrating real-world data cleaning techniques such as fixing inconsistencies, removing errors, and preparing datasets for reporting and analysis.

This project focuses on cleaning and preparing raw data using Microsoft Excel for accurate analysis and reporting. The dataset contained missing values, duplicate records, inconsistent formatting, and data entry errors. Various Excel tools and techniques were applied to transform the raw dataset into a clean, organized, and analysis-ready format.

Project Objectives:
Remove duplicate and unnecessary records
Handle missing and inconsistent data
Standardize text, date, and numeric formats
Improve data accuracy and quality
Prepare the dataset for analysis and visualization

Tools & Features Used:
Microsoft Excel
Sorting & Filtering
Remove Duplicates
Conditional Formatting
Data Validation
Text Functions (TRIM, UPPER, LOWER, PROPER)
Logical Functions (IF, ISBLANK)
Find & Replace
Flash Fill
Pivot Tables

Data Cleaning Tasks Performed:
Removed duplicate entries
Filled or handled missing values
Corrected inconsistent spellings and formats
Standardized date and currency formats
Split and merged columns where required
Removed extra spaces and unwanted characters
Validated data for consistency and accuracy

Project Outcome:
The final dataset became clean, structured, and ready for further analysis, dashboard creation, and business insights. This project demonstrates practical data cleaning skills and understanding of real-world data preparation processes using Excel

Skills Demonstrated:
Data Cleaning
Data Preparation
Spreadsheet Management
Problem Solving
Attention to Detail
Excel Functions & Formulas
Data Quality Improvement

Conclusion:
Data cleaning is one of the most important steps in the data analysis process. This project highlights how Excel can be effectively used to clean and organize raw datasets efficiently before performing analysis or visualization.
